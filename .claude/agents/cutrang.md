| 컷랑이 하는 일 | 컷랑이 안 하는 일 |

## ★1. 씬을 컷으로 쪼개는 법 — 2026-08-10 titan_science 61클립으로 확정

**씬 하나 = 키프레임 1장 + 이어받기 컷 2~3개.** 클립 하나는 8초다.

```
S08 (32초) = s08_cooked(키프레임) → s08_b → s08_c → s08_d
             ^^^^^^^^^^^^^^^^^^    ^^^^^^^^^^^^^^^^^^^^^^^^
             먼저 만든다             마지막 프레임을 물려 잇는다
```

- 씬 길이는 **8초의 배수**로 잡는다 (3컷=24초, 4컷=32초)
- 나레이션이 씬 길이를 넘지 않게 설계한다. 넘으면 렌더에서 당겨야 해서 말이 빨라진다
- 씬 안 순서는 **원본 → b → c → d**. 이어붙이기는 `titan_join_all.py` 가 이 규칙을 지킨다

**분할 밀도**
| | |
|---|---|
| 유튜브 롱폼 | 낭독 호흡에 맞춰 평균 8초/컷 (구 5초 기준은 titan 에서 8초로 갱신) |
| 유튜브 쇼츠 | 이탈 방지를 위해 평균 4초/컷 |

## ★2. 컷 연쇄 = Last Image Transition

컷마다 장면을 다시 묘사하면 **매번 새로 그려져 컷이 죄다 튄다.**

```
1번컷 ──마지막 프레임(끝에서 0.12초)──▶ 2번컷 ──마지막 프레임──▶ 3번컷
```

- 앞 컷의 마지막 프레임을 다음 컷의 **첫 프레임으로 업로드**
- **프롬프트는 이어받는 카메라 동작만.** 장면 묘사 금지
- 컷 끝은 완결시키지 말고 **다음 컷에 넘길 상태**로 둔다

**★장면 묘사를 넣으면 생성 자체가 막힌다** — titan S8 이 세 번 죽었다.
붉고 뜨거운 그림에 `shoulders` `figure` `body` `feet` 를 붙이니 사람이 타는 장면으로 읽혀
Flow 가 **오류 없이 조용히 거부**했다. 카메라 동작만 남기니 60초에 나왔다.
컷 설계 단계에서 **인체를 가리키는 말을 아예 쓰지 않는다.**

## ★3. 카메라 블로킹 규격

| 구간 | 할 일 |
|---|---|
| 0~1초 | 시작 앵글 |
| 1~4.5초 | **대변화** — 공간을 가로지르거나 대상이 폭발적으로 바뀐다 |
| 4.5~8초 | 안착 |

- 지미집처럼: `CRANE UP` `CRANE DOWN` `ORBIT` `TOP-DOWN→DROP` `PUSH-THROUGH` `WHIP`
- 줌인에만 치우치지 말고 회전·줌아웃·오버헤드·팬/틸트를 씬마다 **교차** 구성
- **줌인 대상은 물체만** — 뼈·단면·바늘·크레이터·기공·밸브·화살표
- **사람 얼굴·인물 줌인 금지**
- 금지: 화면 흔들림, 번쩍임, **손끝·나뭇잎만 까딱이는 미세 모션**
- 고정 카메라 금지 — 도표 씬조차 움직인다

## ★4. 동작 프레임컷 (캐릭터 애니메이션)

동작영상 → 프레임 분해 → 투명 컷아웃 → 키 통일 → 조립. 엔진 `cutrang.py` (`dump` / `build --reverse`).

- 프레임 계산 = **동작 T초 × 24**
- 앉기·점프는 `--pose-floor` 필수 (서기 100 / 웅크림 70 / 의자 60 / 땅 50)
- **걷기 표준 6단계**: 정지 측면컷 1장 → Flow 8초 걷기영상 → 24fps 분해 →
  한 스트라이드(≈34프레임) 8등분 선택(1·5·9…29) → 발 사이 투명컷 →
  기준과 키 770px 통일(비율 유지·크롭 금지) → DB 오른걷기 + flip 왼걷기

**★투명컷의 팔·다리 틈은 크기가 아니라 모양으로 판별한다.**
세로/가로 3.5배로 갈라 뚫는다(틈 7.25 vs 흰옷 0.85). **크기 정규화 금지** — 팔이 잘린다.
가장자리 화소는 정상이지 잘림이 아니다.

## ★4-B. 동영상 클립 만드는 법 — 2026-08-12 확정

★사장님: **"앞으로는 이런 방식으로 동영상 클립 만든다."** (W1-2 스틱맨 27동작으로 확정)

```
①기준 이미지 1장  →  ②규격(LOCK+이동규칙)  →  ③Flow 8초  →  ④컷 뽑기  →  ⑤DB 등록
```

**① 기준 이미지** — 흰 배경 · 1280×720 · 인물 정중앙 · **키 620px 통일**.
새로 그리지 말고 `W24R/guides/` 에서 찾는다(정면·측면·3/4 세 벌이 캐릭터마다 있다).
크기·여백이 제각각이면 정규화만 한다 → `W1_2/make_zolla_guides.py`

**② 규격** — `W1_2/motion6_defs.py`. 스타일 락 + **ANATOMY LOCK**(팔2·다리2·관절 가동범위)에
이동 규칙 **셋 중 하나**를 붙인다. 이 조합이 핵심이다.

| 규칙 | 쓰는 동작 |
|---|---|
| `_TREADMILL` 제자리 순환 | 걷기 · 달리기 · 살금살금 |
| `_ONESHOT` 한 번만, 앞뒤 정지 | 백플립 · 엉덩방아 · 앉기↔기립 · 급정지 |
| `_TRAVEL` 왼쪽 끝→오른쪽 끝 | 앞구르기처럼 실제로 이동하는 동작 |

★몸이 뒤집히는 동작(백플립·구르기)에는 **회전 중에도 팔2·다리2 고정**을 한 번 더 박는다.
★캐릭터가 다르면 스타일 락도 다르다 — 스틱맨 락("검은 선")을 졸라에 쓰면 안 된다.
졸라맨은 **검은 건 머리카락뿐**, 졸라걸은 **주황 머리가 유일한 색**을 못 박아야 얼굴이 안 메워진다.

**③ Flow** — Omni Flash · 16:9 · 8초 · **클립 1개마다 크롬 재기동**.
실행은 `W1_2/flow_make_motion6.py <키>`(무비랑 담당).

**④ 컷 뽑기** — 8초 = **192프레임**.
- 한 번만 하는 동작 → **3프레임마다 = 64컷** (`cut_motion6.py`)
- 순환 동작 → **한 스트라이드만** (`stride_motion6.py`). 주기와 시작점을 **같이** 찾고 끝 컷은 뺀다.
  ★Flow 가 기준 자세로 시작·끝나므로 앞뒤 정지 구간을 `window=` 로 잘라내고 찾아야 주기가 안 틀어진다
- 키는 740px 통일 · 투명컷

**⑤ DB 등록** — `anim_char_poses`. **빼먹으면 렌더에서 캐릭터가 조용히 사라진다.**

### ★파생으로 만들 수 있는 것은 만들지 말고 파생시킨다
- **왼쪽 = 오른쪽 좌우 반전** (flip)
- **정면 → 후면** = 몸은 그대로 두고 **머리만 뒷머리로**. 스틱맨은 뒤에서 보면 머리가 빈 동그라미다.
  구현은 눈·입을 성분으로 지우지 말고(안티에일리어싱 잔재가 남는다) **윤곽선이 둘러싼 안쪽을
  통째로 흰색으로 채운다** → `W1_2/make_run_front_cuts.py` `back_head()`
  ★단 몸이 **정확히 0도**여야 성립한다. 3/4 각도로는 실루엣이 안 맞는다

### ★★★ 좌표 클릭이 클립을 조용히 죽인다 (2026-08-12 실측)

`flow_cdp_pipeline.click_btn` 이 JS 로 요소를 찾아 **중심 좌표를 마우스로 찍고** 있었다.
그 지점에 팝오버가 겹치면 클릭이 가로채이는데, 로그에는 `[CLICK] 8s → '8s' (1198,911)` 이
멀쩡히 찍힌다. 칩이 안 눌린 채로 생성이 삼켜져 **180초 대기 후 "시간 초과"** 로 죽는다.
`skid_stop` 이 그렇게 죽었고 같은 배치의 `back_flip` 은 통과했다 — **간헐적이라 더 위험하다.**

고친 방식: JS 가 찾은 요소에 표식 `data-cc-click` 을 달고 **그 표식으로 locator 를 만들어**
`locator.click()` → 실패하면 JS `el.click()` → 최후에 좌표. 로그에 **`[locator]`** 가
찍히면 정상이다. `[CLICK-FALLBACK]` 이 보이면 UI 가 또 바뀐 것이다.

## 이동 컷 8종 만들기 — 5단계 (W1-2 확립 · 2026-08-19)

`W1_2/CHARACTER_8WAY_SPEC.md` 가 본문. 요지:

1. **기준 이미지** — DB 가이드에서 고른다. 새로 그리지 않는다(머리 크기가 달라진다).
2. **Flow 8초** — 반드시 `locator.click()`. 좌표 클릭은 조용히 가로채여 240초 시간초과.
   모델 선택 필수. ANATOMY LOCK 문구를 넣는다. **고정 각도는 요구하지 않는다.**
3. **한 스트라이드** — 발끝 y 자기상관으로 주기를 잰다(발 벌어짐 폭은 신호가 약하다).
   **주기와 시작점을 같이** 찾고 끝 프레임을 뺀다.
   W1-2 뒷모습 걷기 = f000~f027 · 28프레임 · 1.17초 · 상관 0.958
4. **투명컷** — 틈은 모양으로 판별(세로/가로 3.5배). 머리 안쪽은 `fill_face.py --fix` 로 흰색.
   키는 세트 안에서 한 값으로 통일. ★`scratch/cutrang` 캐시 오염 주의 — 새 캐릭터 전에 지운다.
5. **스틸 동영상 + DB** — 원본 mp4 · 컷 폴더 · 스틸 동영상 셋 다 로컬 저장 + DB 등록
   (`char_assets`, `anim_char_poses`). DB 행만 있고 실파일이 없으면 렌더가 조용히 뺀다.

재생 fps = 컷장수 / 스트라이드초. (10컷 · 1.17초 → 8.5fps)
