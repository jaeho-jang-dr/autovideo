## 배운 것 — 다음에 반복하지 말 것

### Flow 는 3/4 각도를 고정 못 시킨다

45도·135도를 클립 내내 유지하라고 하면 **안 된다.** 8초·10초 양쪽 다 실패했다.
도 단위로 명시하고 보이는 것을 일일이 나열해도 소용없다.

원인은 프롬프트가 아니라 **기준 이미지**다. 스틱맨은 선 그림이라 각도 단서가
없어서, 참조가 정면이면 Flow 가 아는 것 중 제일 가까운 옆모습으로 떨어진다.
파라메트릭으로 45도/135도 가이드를 그려 줘도(`make_q_guides.py`) 약했다.

**대신 회전하는 과정을 통째로 만들게 하면 잘 된다.** 그 안에 모든 각도가 있으니
원하는 프레임을 골라내면 된다. 끝을 **180도**로 잡아야 그 구간을 반복하며
크기만 줄여 멀어지게 쓸 수 있다 — 135도로 끝내면 그게 안 된다.

회전은 **한 방향으로만** 못 박아야 한다. 되돌아오기·좌우 흔들림·계속 돌기·
어깨 너머로 돌아보기를 각각 금지해야 왔다 갔다 하지 않는다.

### 순환 컷은 한 스트라이드만, 이음매는 숫자로 검사

주기와 시작점을 **따로** 찾으면 틀린다. 걷기를 30프레임으로 어림잡았더니
이음매 0.227 < 이웃 0.305 로 절뚝였다. 한 구간 전체가 다음 구간과 겹치는지를
재서(실루엣 IoU) 둘을 **같이** 골라야 한다 → 29프레임이 정답이었다.

끝 프레임은 시작과 같은 자세라 **뺀다.** 넣으면 같은 자세가 두 번 나온다.

샘플 간격: 걷기 3중 1(8fps 재생) · 달리기 **전 컷**(24fps). 달리기는 빠른
동작이라 건너뛰면 튄다.

### Flow 동영상 길이는 4s / 6s / 8s / 10s

없는 값을 누르면 오류 없이 조용히 8초로 나온다. `probe_durations.py` 로
먼저 확인해라 — 크롬 한 번 띄우는 1분이 생성 10분보다 싸다.

### 뒷모습 걷기·달리기는 다리 동작이 죽는다

보폭이 깊이 방향이라 화면에서 거의 안 보인다. 걷기는 잔걸음, 달리기는 팔만
펌핑하고 무릎이 안 올라온다. 순환 소재로는 약하므로 **좌표 이동 + 원근 축소**로
보완해야 달려 나가는 것으로 읽힌다.

**남은 것**: 앞에 두 구간을 붙여 `talk → run → turn → away` 로 잇는다.

| 구간 | 하는 일 | 발 y | 키 |

| run | 측면으로 오른쪽으로 달려 나간다 | 706 고정 | 573 고정 |
| turn | 90도 → 180도로 돈다 | 706 고정 | 573 고정 |
