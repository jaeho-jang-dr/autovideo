## 세트 정의 — 캐릭터 하나당 8종

방향 4개(정면·후면·좌·우) × 이동 2종(걷기·달리기) = **8종**.
좌우는 한쪽만 만들고 **실파일을 반전**해 반대쪽을 만든다(flip 플래그 아님 —
반전본을 실제 파일로 저장한다. 렌더 때 이중 반전 사고를 막는다).

| 키 | 뜻 | W1-2 스틱맨 실측 |
|---|---|---|
| `walk_front_*` / `run_front_*` | 카메라 쪽으로 다가옴 | run_front 44컷 |
| `walk_back_*` / `run_back_*` | 카메라 반대로 멀어짐 | run_back 44컷 · walkback 10컷 |
| `walk_side_r` / `run_side_r` | 오른쪽으로 | walk_side 10컷 · run_side 20컷 |
| `walk_side_l` / `run_side_l` | (오른쪽 반전) | 같은 장수 |

부수 컷 — 필요할 때만: `walk_exit_*`(걷다 멀어짐) · `run_exit_*` · `*_turn_*`(회전).

## 만드는 5단계

### ① 기준 이미지 한 장
그 캐릭터의 **DB 가이드 3종**(정면·측면·3/4)에서 해당 방향 한 장을 골라
1024 흰 캔버스에 얹는다. 새로 그리지 않는다 — 머리 크기가 달라진다.
후면은 정면 가이드에서 **머리만 빈 원으로 바꿔** 파생한다.

### ② Flow 로 8초 영상
`flow_make_motion6.py` — 가이드 이미지 + 프롬프트.
* 반드시 **`locator.click()`** 으로 조작한다. 좌표 클릭은 조용히 가로채여
  240초 시간초과로 끝난다([[flow-coordinate-click-silent-fail]]).
* 모델을 반드시 고른다. 안 고르면 오류 없이 실패하고 프롬프트가 지워진다.
* 프롬프트에 **ANATOMY LOCK**(팔·다리·손가락 개수, 관절 가동범위, 양쪽 흰 운동화)을
  못 박는다([[veo-anatomy-lock-prompt]]).
* 45도 같은 **고정 각도는 요구하지 않는다** — Flow 가 못 한다.

### ③ 한 스트라이드 잘라내기
192프레임(8초·24fps)을 분해해 **걸음 주기**를 찾는다.
* 주기는 **발끝 y 차이의 자기상관**으로 잰다. 발 벌어짐 폭은 신호가 약하다.
* **주기와 시작점을 같이** 찾아야 한다 — 따로 구하면 이음매에서 절뚝인다.
* 끝 프레임은 뺀다(첫 프레임과 같은 자세라 두 번 밟는다).
* W1-2 실측: 뒷모습 걷기 한 스트라이드 = **f000~f027, 28프레임, 1.17초, 상관 0.958**

### ④ 투명컷
`cutrang.py dump` → 배경 제거 → `build` 로 키 통일.
* 팔·다리 사이 틈은 **모양으로 판별**한다(세로/가로 3.5배). 크기로 자르면
  흰 옷까지 뚫린다([[cutrang-transparent-cut-gap-rule]]).
* 머리 안쪽이 뚫려 있으면 **흰색으로 채운다** — `fill_face.py --fix <키>`.
  안 채우면 배경이 얼굴로 비쳐 보인다.
* 키는 세트 안에서 **한 값으로 통일**(W1-2 스틱맨 1023px).
* ★캐시 오염 주의 — `scratch/cutrang/dump/seq` 에 앞 캐릭터 프레임이 남아
  `--video` 를 무시하고 재사용된다. 새 캐릭터 시작 전 그 폴더를 지운다.

### ⑤ 스틸 동영상 + DB 등록
컷을 이어 붙여 **스틸 동영상**을 만들어 눈으로 확인한다(3중 1컷 또는 전량).
```
원본 mp4 · 투명컷 폴더 · 스틸 동영상  → 셋 다 로컬 저장 + DB 등록
  char_assets      (원본·컷세트·스틸)
  anim_char_poses  (컷 한 장씩, pose_name=<키>_NN)
```
DB 행만 있고 실파일이 없으면 렌더가 **조용히 그 캐릭터를 빼고** 그린다.
등록 뒤 `precheck` 로 파일 존재를 확인한다([[precheck-asset-fidelity-before-render]]).

## 재생 fps 정하기

```
fps = 컷장수 / 스트라이드초
  예) 10컷이 한 스트라이드(1.17초) → 8.5fps 가 원속
      44컷이 두 스트라이드(0.60초) → 22fps
```
비트 튜플 9번째 값으로 준다. 이 값만 바꾸면 **이동 속도는 그대로 두고
발놀림만** 빠르게/느리게 할 수 있다.

## 다음 회차 캐릭터에 적용할 때

1. 그 캐릭터의 **가이드 3종이 Flow 로 통일돼 있는지** 먼저 확인
   ([[character-guide-image-flow-unify]]). 엔진을 섞으면 정지↔무빙이 딴사람이 된다.
2. 8종 중 **정면·후면·측면(오른쪽)** 3방향만 Flow 로 만들고, 왼쪽은 반전.
   걷기·달리기는 프롬프트만 바꿔 같은 절차를 두 번 돈다.
3. 세트가 끝나면 **자세별 키 기준**을 맞춘다 — 서기 100 · 구부림 80 · 의자 60 ·
   웅크림 50. 키는 머리끝~발끝만 재고 bbox 로 재지 않는다
   ([[character-pose-height-rubric]]).
4. `stickman` 세트를 표본으로 삼는다 — `assets/graphics/poses/` 에 있는
   `run_front_* / run_back_* / run_side_* / walk_side_*` 가 그것이다.
