1. **[00:00] 씬0** 「안녕하세요! 오늘은 '거센소리'와 '된소리'를 배워볼 거예요.」 — 거센소리 된소리에 ' ' 없애고 나레이터가 읽어
2. **[00:19] 씬2** 「지난 시간에는 부드러운 '예사소리' 'ㄱ', 'ㄷ', 'ㅂ', 'ㅈ', 'ㅅ'를 배웠어요.」 — 여기서 예사소리 에 ' ' 없애고 나레이터가 읽어
3. **[00:26] 씬2** 「지난 시간에는 부드러운 '예사소리' 'ㄱ', 'ㄷ', 'ㅂ', 'ㅈ', 'ㅅ'를 배웠어요.」 — 그 드 브 즈 스 읽는데 너무 오래 걸려 데이타베이스와 시간 차이 0.1 도 없애고 바로 읽어 봐
4. **[00:45] 씬5** 「첫 번째 친구는 '거센소리'예요. 입에서 공기를 확 세게 내뿜는 힘찬 소리죠.」 — 여기 거센소리도 '  ' 빼고 나레이션으로 바로 읽어
5. **[00:59] 씬7** 「'거센소리'는 '예사소리'에 획을 하나 더해 만들어요. "ㄱ"에 획을 더하면 "ㅋ"!」 — 여기도 거센소리 예사소리에 '  ' 다 빼고 나레이터가 빠르게 읽어  그 크 도 사이 시간 간격 0.1초 없이 데이타베이스 성우가 바로 읽어 줘
6. **[01:13] 씬8** 「부드럽던 "ㄱ"가 획 하나로 훨씬 강하고 거센 소리가 되죠.」 — 부드럽던 기억 가 가 아니고 기억 이 로 바꾸자
7. **[01:21] 씬9** 「같은 방법으로 "ㄷ"는 "ㅌ", "ㅂ"는 "ㅍ", "ㅈ"는 "ㅊ"가 돼요.」 — 여기서 더귿은 티긑 비읍은 피읖 지읏은 치읓이 돼요 라고 읽어줘  은 는 이 를 정확 하게 붙여야 해..
8. **[02:23] 씬16** 「두 번째 친구는 '된소리'예요. 목에 힘을 주고 소리를 꽉 조여 내는 단단한 소리죠.」 — 여기 된소리도 '  ' 없애고 나레이터가 된소리 라고 읽어 줘
9. **[02:33] 씬18** 「'된소리'는 '예사소리' 두 개를 나란히 붙여 만들어요. 'ㄱ'가 두 개 모이면 'ㄲ'!」 — 여기 된소리 예사소리에 ' ' 빼고 나레이터가 자연스럽게 읽어줘,
10. **[02:59] 씬20** 「마찬가지로 'ㄷ'는 'ㄸ', 'ㅂ'는 'ㅃ', 'ㅅ'는 'ㅆ', 'ㅈ'는 'ㅉ'가 돼요.」 — 데이타 베이스 소리 간격 0.1초 없이 바로 바로 읽어줘
11. **[04:53] 씬34** 「오늘은 한글의 '거센소리'와 '된소리'를 배웠어요. 매일 조금씩 발음을 익혀 보세요.」 — 여기도 거센소리 된소리 에 '  ' 없애고 나레이터가 바로 읽어줘
