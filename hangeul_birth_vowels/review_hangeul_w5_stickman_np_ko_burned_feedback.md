# 교정 피드백 — 한글강의 W5 한글판 · 북촌 한옥마을 배경 (13씬)

> review_lesson.py 수집. 감독(Claude)이 이 파일을 읽어 해당 씬만 교정한다.

1. **[00:04] 씬1** 「오늘은 두 소리가 미끄러지며 만나는 '이중모음'과 '반모음 활주'를 배워볼 거예요.」 — 여기 이중모음 반모음 '  ' 없애고 나레이터가 바로 읽어줘
2. **[00:20] 씬4** 「두 모음이 이어져 한 소리처럼 나는 것을 '이중모음'이라고 해요.」 — 여기서도 이중모음에 '  ' 없애고 나레이터가 바로 읽어줘
3. **[00:33] 씬6** 「이중모음의 앞에는 짧게 스쳐 지나가는 '반모음'이 숨어 있어요.」 — 여기 반모음도 '  ' 없애고 나레이터가 바로 읽는다
4. **[00:50] 씬8** 「먼저 'ㅣ' 활음이에요. 'ㅣ'에서 'ㅏ'로 빠르게 미끄러지면 'ㅑ'가 돼요. 야!」 — 여기는 ㅣ + ㅏ    ㅑ   이렇게 한줄로 만들어줘
5. **[01:20] 씬11** 「모두 'ㅣ'에서 부드럽게 미끄러지는 소리랍니다.」 — 여기는 ㅣ + ㅓ     ㅕ
          ㅣ + ㅗ     ㅛ
           ㅣ + ㅜ    ㅠ         이럴게 만들어줘
6. **[02:18] 씬18** 「'사과'의 '과' 소리죠.」 — 여기는 윗줄에  ㅗ + ㅏ      ㅘ
                     사 과               이렇게 만들어줘
7. **[02:23] 씬19** 「'ㅜ'와 'ㅓ'가 만나면 'ㅝ', 'ㅗ'와 'ㅣ'가 만나면 'ㅚ',」 — 여기는  ㅜ + ㅓ   ㅝ
           ㅗ + ㅣ   ㅚ
           ㅜ + ㅣ    ㅟ     이렇게 쓰고 아래뒤가 겹치지 않고 좀 띄워줘
8. **[03:08] 씬24** 「마지막은 'ㅢ'예요. 'ㅡ'에서 'ㅣ'로 미끄러지는 특별한 소리죠.」 — 여기는 위에   ㅡ + ㅣ       ㅢ
                     의 자             이렇게 써줘
