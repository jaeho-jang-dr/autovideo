# 교정 피드백 — 한글강의 W20 한글판 (동동체 파라메트릭·발음기호)

> review_lesson.py 수집. 감독(Claude)이 이 파일을 읽어 해당 씬만 교정한다.

1. **[01:52] 씬16** 「'112'와 ' [wa] 119'는 24시간, 요금도 없어요.」 — 여기 고쳐야 한다 자막 112와 119는 24시간, 요금도 없어요 는 전부 나레이터가 읽는다 중간에 wa 뺀다, 24를 영어 나레이터가 읽었는데 선희가 읽는다  이거 확실 하게 고치자
2. **[04:53] 씬38** 「'112'와 ' [wa] 119'는 통역 도움도 받을 수 있어요.」 — 여기도 와 로 바꾸어줘
3. **[05:29] 씬42** 「'112'와 ' [wa] 119' 신고까지 익혔어요.」 — 여기도 영어 wa 자막 빼줘 한글로 와 를 적어
